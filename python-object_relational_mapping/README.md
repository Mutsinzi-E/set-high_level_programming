# Python - Object-relational mapping

This directory contains Python scripts that demonstrate how to interact with a MySQL database using the `MySQLdb` module.

## Task 0: Get All States

`0-select_states.py` connects to a MySQL database running on `localhost` port `3306`, retrieves all records from the `states` table, sorts them by `id` in ascending order, and displays each record.

Usage:

```bash
./0-select_states.py <mysql_username> <mysql_password> <database_name>
