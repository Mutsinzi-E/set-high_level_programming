========================
1. Divide a Matrix
========================

Import the function:

    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

Basic division:

    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> matrix_divided(matrix, 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

Original matrix is not modified:

    >>> matrix
    [[1, 2, 3], [4, 5, 6]]

Division by a float:

    >>> matrix_divided([[1, 2], [3, 4]], 2.0)
    [[0.5, 1.0], [1.5, 2.0]]

Negative divisor:

    >>> matrix_divided([[10, -10], [5, -5]], -2)
    [[-5.0, 5.0], [-2.5, 2.5]]
