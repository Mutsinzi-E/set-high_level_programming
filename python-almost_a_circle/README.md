# Python - Almost a Circle

This project contains unit tests for the Python Almost a Circle project.

## Task 0: If it's Not Tested it Doesn't Work

The `tests/` directory contains unit tests for the project models.

## Running the tests

From the `python-almost_a_circle` directory, run:

    python3 -m unittest discover tests

## PEP 8 validation

Run:

    pycodestyle models tests
